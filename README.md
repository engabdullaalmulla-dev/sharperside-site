# sharperside.com

The public site for **Sharper Side** — statistical analysis of football fixtures.

**Generated, not maintained.** Every page here is written by `src/website.py` in
the private engine repository and published with `scripts/publish_site.py`.
Editing a file here puts it out of step with the generator, which is the only
thing anyone will re-run.

Nothing in this repository is secret: five HTML pages, a favicon, and a CNAME.
The model, the data and the forecasting code are not here.
